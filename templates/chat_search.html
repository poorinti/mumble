1. สิทธิ์และป้ายขอบเขต

ADMIN · ดูได้ทุกห้องUSER · 2 ห้อง
  • Admin เห็นทุกสถานี ทุกห้อง เปิดเสียงและ Export ได้ทั้งหมด
  • User เห็นเฉพาะห้องที่ Admin ผูกกับบัญชี
  • ถ้ายังไม่ได้รับสิทธิ์ห้อง ระบบจะแสดงผลลัพธ์เป็นศูนย์

2. ช่องค้นหาหลัก

ข้อความ คำพูด หรือ ว.8ค้นหา
  • ค้นหาคำเดี่ยว ประโยค ชื่อเหตุการณ์ หรือรหัสวิทยุได้
  • กด Enter เพื่อค้นหา หรือ Ctrl + K เพื่อโฟกัสช่องนี้ทันที
  • คำที่ตรงจะถูกไฮไลต์ในผลลัพธ์

3. สถานี ผู้พูด และเวลา

สถานี: เลือกหลายรายการผู้พูดตั้งแต่ → ถึง
  • สถานี เลือกหลายสถานีได้ด้วย Ctrl/Command
  • ผู้พูด พิมพ์ชื่อหรือเลือกจากคำแนะนำ
  • ตั้งแต่/ถึง จำกัดวันและเวลา; เว้นว่างหมายถึงไม่จำกัด

4. ประเภทข้อมูล

เสียงถอดข้อความAlertแชทTTSPTT
  • Voice transcript เสียงที่ AI ถอดเป็นข้อความ
  • Alert รายการที่ตรงคำเฝ้าระวัง
  • Text chat แชทใน Mumble, TTS ข้อความ AI พูด, PTT ไมค์เว็บ

5. ตัวกรองขั้นสูง

มีไฟล์เสียงKeywordConfidence ≥ 0.80
  • หลักฐานเสียง เลือกทั้งหมด/มีเสียง/ไม่มีเสียง
  • Keyword และ Incident status จำกัดเฉพาะรายการที่เกี่ยวข้อง
  • Confidence ตัดผลถอดเสียงที่ความมั่นใจต่ำ
  • คำใกล้เคียง รองรับคำสะกดคลาดเคลื่อน ตั้งแต่ 3 ตัวอักษร

6. อ่านผลลัพธ์

เจ้าหน้าที่-01 · 14:32 · มีเสียง
“ขอกำลังเสริมบริเวณจุดตรวจ...”
  • แถบบนแสดงจำนวนผล เวลาใช้ค้นหา และเรียงล่าสุด/เก่าสุด
  • ป้ายใต้ข้อความบอกประเภท Keyword เสียง และ Incident
  • กด โหลดผลลัพธ์ถัดไป เพื่ออ่านต่อโดยไม่โหลดรายการเดิมซ้ำ

7. รายละเอียดและเสียง

▶ เล่นเสียงบริบทก่อน–หลัง 10 ข้อความ
  • คลิกผลลัพธ์เพื่อเปิดแผงรายละเอียดด้านขวา
  • แสดงสถานี ห้อง ผู้พูด เวลา Confidence Keyword และ SHA-256
  • เครื่องเล่นเสียงจะแสดงเมื่อไฟล์ยังอยู่ และบริบทใช้ห้อง/สถานีเดียวกัน

8. จัดการหลักฐาน

Bookmark / Noteแก้ Transcriptเปิด Incident
  • Bookmark / Note ใส่ Tags และหมายเหตุส่วนตัว
  • แก้ Transcript สร้าง Revision ใหม่และเก็บต้นฉบับไว้
  • Incident ระบุชื่อ ระดับความรุนแรง และหมายเหตุ
  • ทุกการทำรายการถูกบันทึก Audit log

9. บันทึกชุดค้นหาและ Export

บันทึกชุดค้นหาส่งออก CSV
  • บันทึกตัวกรองปัจจุบันไว้เรียกใช้ซ้ำจากรายการด้านบน
  • ตัวเลือกแจ้งเตือนเป็นการเตรียมชุดค้นหาสำหรับระบบแจ้งเตือน
  • CSV ใช้ตัวกรองและสิทธิ์ห้องเดียวกับหน้าจอเสมอ

10. ล้างตัวกรองและแก้ปัญหา

ล้างทั้งหมดค้นหาตามเงื่อนไข
  • ล้างทั้งหมด คืนค่าตัวกรองและ URL แล้วค้นหาใหม่
  • ไม่พบข้อมูล: ตรวจสิทธิ์ห้อง ช่วงเวลา ประเภท และลองปิดคำใกล้เคียง
  • เปิดเสียงไม่ได้: ไฟล์อาจหมดอายุ retention หรือถูกย้าย
  • กด Esc เพื่อปิดรายละเอียดบนจอขนาดเล็ก
