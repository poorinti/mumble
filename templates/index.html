# ห้องปฏิบัติการ (2 นาย)🔇✏️⚙️
🟢 เจ้าหน้าที่-011🔇 ปิดไมค์💬 ข้อความ👢 เตะ
✓ปุ่มคำสั่งอยู่ด้านขวาของชื่อผู้ใช้ และปุ่มควบคุมทั้งห้องอยู่ที่หัวห้อง
  • แผนผังห้องจะแสดงผู้ใช้งานแบบสดและจำนวนผู้ใช้
  • ใต้ชื่อผู้ใช้จะแสดงเวลาที่อยู่ในห้องปัจจุบัน และเริ่มนับใหม่เมื่อย้ายห้อง
  • กดปุ่ม Q ที่หัวห้อง เลือกผู้บัญชาการ แล้วเปิด Quiet Mode เพื่อปิดไมค์ทุกคนรวมผู้เข้าใหม่ ยกเว้นผู้บัญชาการ
  • คลิกผู้ใช้เพื่อดูคำสั่ง เช่น ย้ายห้อง ปิดไมค์ ปิดหูฟัง เตะ หรือแบน
  • กด ⋮ ที่แผง “สถานะระบบ” เพื่อเปิดเมนูรีสตาร์ต ตั้งค่าขั้นสูง เปลี่ยนรหัสผ่าน หรือดู Log ของเซิร์ฟเวอร์
STEP 03 · SEARCH

ค้นหาแชทและเสียงย้อนหลัง

✓กด “ประวัติ” บนแถบด้านบน ระบบค้นหาแชทและเสียงจะเปิดในโซนขวา โดยไม่ออกจาก Dashboard
  • กด ประวัติ บน Header เพื่อเปิดหน้าค้นหาแชทและเสียงย้อนหลัง
  • พิมพ์คำค้น แล้วกรองสถานี ผู้พูด ช่วงเวลา Keyword Confidence หรือ Incident
  • เปิด “คำใกล้เคียง” เมื่อต้องการค้นหา transcript ที่สะกดคลาดเคลื่อน
  • คลิกผลลัพธ์เพื่อดูบริบทก่อน–หลังและเล่นไฟล์เสียงหลักฐาน

✓Admin เปิด “ผู้ใช้ระบบ” เลือกห้องที่บัญชีเห็นข้อมูลย้อนหลัง แล้วกดบันทึก
  • User ใช้คำสั่งควบคุมได้ทั้งหมด เช่น ย้าย/เตะ/แบน/ปิดไมค์/ส่งข้อความ/ตั้งค่าห้อง แต่สร้างหรือลบห้องไม่ได้

  • Admin ทำได้เหมือน User และเพิ่ม/ลบห้อง จัดการสถานี และสร้างบัญชีผู้ใช้ได้
  • Admin เปิดเมนู ผู้ใช้ระบบ เพื่อสร้างบัญชี เปลี่ยนบทบาท รีเซ็ตรหัสผ่าน หรือปิดใช้งานบัญชี
  • บัญชีถูกเก็บใน PostgreSQL ด้วย password hash และระบบจะไม่อนุญาตให้ลบ/ลดสิทธิ์ Admin คนสุดท้าย
